# To-Do List App

Um aplicativo simples de lista de tarefas desenvolvido em Java com Swing.

## Funcionalidades

- Adicionar tarefas à lista  
- Remover tarefas selecionadas  
- Interface gráfica amigável  

## Como executar

1. Certifique-se de ter o Java instalado na sua máquina.
2. Clone este repositório:
git clone https://github.com/ainda-nao-esta-pronto
3. Compile e execute o código: **javac ToDoListApp.java java ToDoListApp**

## Tecnologias utilizadas

- Java  
- Swing (GUI)
